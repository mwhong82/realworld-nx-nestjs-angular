# 튜토리얼 생성/업데이트

$ARGUMENTS 주제로 튜토리얼을 생성하거나 업데이트합니다.

## 워크플로우

### 1단계: 소스 수집

대화 로그에서 실제 사용된 프롬프트와 결과를 추출:

```bash
# 대화 로그 위치
ls ~/.claude/projects/<프로젝트명>/
```

로그 파일(`.jsonl`)에서 다음을 추출:

- **사용자 프롬프트**: 실제 입력한 요청 (오타 정정)
- **에이전트 응답**: 실행된 작업과 결과
- **에러/해결**: 발생한 문제와 해결 과정

### 2단계: 구조화

튜토리얼 구조:

```markdown
# 제목

## 개요

- 목적, 대상 독자, 사전 요구사항

## 단계별 가이드

### Phase N: 단계명

- **목표**: 이 단계에서 달성할 것
- **프롬프트**: 실제 사용한 프롬프트 (코드블록)
- **결과**: 생성/수정된 파일, 주요 출력
- **주의사항**: 발생 가능한 에러와 해결법

## 체크리스트

- [ ] 각 단계 완료 확인 항목

## 트러블슈팅

- 자주 발생하는 문제와 해결법
```

### 3단계: 프롬프트 정제

로그에서 추출한 프롬프트를 튜토리얼에 포함할 때:

- **오타 정정**: 원본의 오타/탈자를 올바르게 수정
- **맥락 보강**: 필요 시 프롬프트에 맥락 설명 추가
- **일반화**: 프로젝트 특정 값을 `<placeholder>`로 대체 가능한 부분 표시
- **순서 정리**: 실제 실행 순서대로 정렬

### 4단계: 검증

- 각 단계의 프롬프트가 실제로 동작하는지 논리적 검증
- 빠진 단계나 전제 조건이 없는지 확인
- 초보자가 따라할 수 있는 수준의 설명인지 확인

## 출력 위치

- 튜토리얼 문서: `docs/` 디렉토리
- 파일명 컨벤션: `docs/<주제>-tutorial.md`

## 업데이트 모드

기존 튜토리얼을 업데이트할 때:

1. 기존 문서를 Read로 확인
2. 새로운 내용을 적절한 위치에 추가
3. 기존 내용과 중복/모순이 없는지 확인
4. 버전/날짜 정보 업데이트
